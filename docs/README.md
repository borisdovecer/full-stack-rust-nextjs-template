# Docs

Start here.

## Reading order

1. [system/architecture.md](system/architecture.md): what runs where.
2. [rules/development.md](rules/development.md): how work moves from a note to finished code.
3. The system page for the part you are about to change.

## Folders

| Folder | Holds |
|---|---|
| [system/](system/) | how the app works today. The in-app Help page shows these, in the order of [system/README.md](system/README.md) |
| [rules/](rules/) | the rules people and agents follow, and the document templates |
| [bug_report/](bug_report/) | open bug reports, one file each |
| [feature_request/](feature_request/) | open feature requests, one file each |
| [archived/](archived/) | finished or outdated documents, in the same folder they came from. Never deleted |

## Rules

| File | Covers |
